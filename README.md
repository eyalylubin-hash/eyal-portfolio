# Eyal Lubin — Portfolio (self-contained map)

Upload the ZIP directly through Vercel Drop, or unzip and upload the whole folder. The **interactive Mitzvah Miles map is embedded inside `index.html`**, not loaded from a separate path. Its map data is the original friend-supplied HTML with only the broken background tile provider replaced by OpenStreetMap.

Click **Expand map** for a full-screen map; click **Close map** or press Escape to return.

There is no separate map HTML file to load, so the map cannot fail with the previous missing-file 404. The full-map button expands the embedded map on the same page.

The map uses external Leaflet JavaScript and OpenStreetMap map tiles, so an internet connection is needed to display and interact with it. `assets/Eyal_Lubin_Resume.pdf` is the resume link.
